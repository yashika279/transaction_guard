# Security Policy

## Supported versions

Security fixes are applied to the latest released version of TransactionGuard.

## Reporting a vulnerability

Please report security issues privately by emailing **yashikavijay2799@gmail.com**.

Do not open a public GitHub issue for vulnerabilities until a fix is available.

Include:

- A description of the issue
- Steps to reproduce
- Impact assessment if known

You should receive an acknowledgment within a few days.
